Keep the crew together. Keep the whole game folder.

Starting PirateCraft

Extract the complete Windows package, then run PirateCraft-Build-155.exe inside that folder. Keep its runtime DLLs and config folder beside it. You can rename or move the entire folder; do not copy only the EXE.

Online co-op

  1. Both players need a free Epic Games account and compatible PirateCraft versions.
  2. Open Multiplayer and choose Epic Login. Complete Epic’s own sign-in and consent screen if prompted.
  3. The host opens a Journey and selects Host Game, then Invite / Friends.
  4. The guest accepts the invitation through the Epic Social Overlay.

Public Epic access is pending review. These steps describe the integrated flow, not a claim that public access or the two-account test is already approved.

“Epic: unavailable”

Restore the complete package. Missing runtime files prevent Epic login. Do not download DLLs from third-party DLL sites. Your game saves are separate from the installation folder.
